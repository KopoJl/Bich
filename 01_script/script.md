# «03:06» — сценарий

**Логлайн.** Вдова-расшифровщица записывает ночную тишину своего дома, чтобы доказать себе, что не сходит с ума. Но каждая прослушанная запись приводит в дом того, кто на плёнке шепчет её собственным голосом.

**Хронометраж:** ≈ 99 с · 16:9 · 24 fps · реплики по-английски (Лондон), перевод в субтитрах.

## STRUCTURE / HOOK

- `STRUCTURE: №9 «Временная петля» — одна ночь (03:06 → 03:07) проходит трижды: повтор, вариация, выход. Локация и Light Lock одинаковые во всех проходах, меняются действия Рут и сила аномалий; это и есть нарастание. Петля держит главный приём Кона — граница яви и восприятия сдвигается незаметно, — а для ИИ это самый безопасный вариант: жёсткие Locks, одна комната. Вопрос зрителя: «Что случится в 03:07 и выберется ли она из этой ночи?»` Из структуры №8 «Мозаика» взята одна неоднозначная деталь: на рассвете часы показывают 03:06.
- `HOOK: информационный разрыв + in medias res. 0,3 с — её шёпот в микрофон: «Three-oh-six. The house is quiet.»; в кадре крутится кассета, а в глубине на правой трети — чёрная щель приоткрытой двери. Зачем записывать пустую комнату в три часа ночи?`

## Драматургия (A.12)

| | |
|---|---|
| Цель (одна) | доказать записью, что дом обычный, а значит, она не безумна |
| Направление сцены (общее, невысказанное) | пережить ночь, не признав, что в доме кто-то есть |
| Мотив | страх стать как мать, которая «слышала вещи»; горе по дочери |
| Препятствие | чтобы записать тишину, надо её слушать, а слушание зовёт звуки. Под угрозой вся цель: каждое «доказательство» оборачивается против неё |
| Тактика 1 (проход 1) | записывать и называть каждый звук бытовым именем («трубы», «автобус») |
| Тактика 2 (проход 2) | перемотать и прослушать запись, сверить факты → находит на плёнке второй шёпот |
| Тактика 3 (проход 3) | вернуть контроль: свет, рубильник → не работает |
| Поворот | действие героини оборачивается против неё: шёпот на плёнке — её собственный голос, замедленный. Её записи и есть дверь |
| Выход | она уничтожает доказательство: вытягивает ленту из кассеты |
| Сдвиг оценки | «собранная скептичка» → «напуганная, теряет контроль» → «смелая: отказалась от доказательства, чтобы остаться в живых» |
| Финал (цикличный) | рассвет, Жильца нет, но часы стоят на 03:06, а дверца шкафа снова приоткрыта на 4 см |

## Биты

| Проход | Шоты | Что происходит | Время |
|---|---|---|---|
| 1 — явь | SH010–SH040 | запись → пролёт по комнате → скрип над головой, она смотрит на дверь → 03:07, на 0,4 с мелькает глаз, лампа гаснет | 0–28 с |
| 2 — сдвиг | SH050–SH080 | снова 03:06: чай опять горячий, кассета перемотана → она слушает запись, слышит второй шёпот → проигрыватель сам ставит детскую песню дочери, замедленную; тень распятия ползёт → она подходит к шкафу, лампа гаснет, мёртвая тишина | 28–59 с |

## Реплики (английский; адресат указан)

- SH010 — Рут, в микрофон магнитофона, шёпотом: «Three-oh-six. The house is quiet.»
- SH030 — Рут, себе, почти без голоса, глядя на дверь: «Pipes.»
- SH060 — с плёнки: её голос «…the house is quiet» и под ним второй, медленный шёпот теми же словами.
- SH110 — с плёнки, громко из комнаты: «Three-oh-six.»
