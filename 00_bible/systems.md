# Ваши системы → текст промта

Здесь собраны ваши правила: как каждое из них пишется в промте и в каких шотах применяется. Слово-термин в промт не попадает: модель не знает, что такое «follow-through», зато понимает «край кардигана догоняет корпус через 0,3 с».

## 1. Принципы движения персонажей

| Ваш принцип | Как пишем в промте (реалистичный взрослый персонаж) | Пример из фильма |
|---|---|---|
| Сжатие и растяжение | только мягкие ткани и одежда: щёки при сглатывании, плечи 1–2 см на вдохе, ткань собирается в складки на сгибах; скелет не тянется | SH060: горло сжимается при сглатывании, плечи поднимаются на 2 см |
| Подготовка (anticipation) | короткое противодвижение перед действием, 0,2–0,4 с | SH010: палец зависает над кнопкой на 0,3 с; SH100: перед рывком вес уходит назад на пятки |
| Сценичность (staging) | одно действие на шот; главное — в самой контрастной точке кадра | щель двери в SH010 — самое тёмное место |
| Сквозное движение и захлёст | ткань и волосы запаздывают по весу: кардиган на 0,4–0,5 с, волосы на 0,2–0,3 с, мокрый плащ на 0,5 с | SH100: полы кардигана летят назад, догоняют на остановке |
| Зум | не используется: приближения только физические (наезд, дрейф), чтобы сохранить параллакс нарисованных слоёв |
| Смягчение в начале и в конце | разгон и торможение словами: `slows to a stop over 0.8 s` | SH010: катушки останавливаются за 0,8 с |
| Дуги | `the hand travels in a smooth arc`; голову ведёт взгляд, голова догоняет через 2–4 кадра | SH030: поворот головы по дуге вверх и вправо |
| Вторичное действие | одно непроизвольное действие, а не жест «для красоты» | SH050: большой палец трёт ободок чашки |
| Расчёт времени | каждое действие с секундами (B.8) | сумма отрезков равна длине клипа |
| Утрирование | дозированно и только в паранормальном: тень вытягивается на 2–3 длины, Жилец на 0,6 м выше двери | у Рут утрирования нет |
| Привлекательность | читаемый силуэт, асимметрия лица, живые руки | Рут узнаётся по силуэту кардигана |
| Отсутствие лишней жестикуляции | в каждом окне 1 с меняется одно: шаг задачи или тело | никаких жестов «я боюсь» |
| Чёткая партитура эмоций | ACTING TASK: направление, мотив, цель, препятствие, тактика глаголами по секундам (S.10) | см. каждый шот |
| Сохранение объёма массы | `her volume stays constant, the body does not stretch or shrink` в POSITIVE LOCKS | во всех шотах с Рут |
| Соответствие сценарной арке | интенсивность тела по проходам: 1–2 → 2–3 → 3–4 | Рут собрана в проходе 1, мечется в проходе 3 |

## 2. Камера: где применяется и где исключена

| Приём | Шоты | Ваше условие | Проверка |
|---|---|---|---|
| Медленный зловещий наезд | SH030 (дверь), SH080 (шкаф, как «слепой наезд») | взгляд героя прикован к тёмному проёму; не в динамике | PASS: обе сцены статичные |
| Подглядывающая панорама из-за угла | SH050 (из щели шкафа) | через косяки и мебель, не на открытой локации | PASS: комната, кадрирует дверца шкафа |
| Парящая невесомая камера | SH070 | потустороннее присутствие под потолком; не в реалистичных сценах | PASS: второй проход, после сброса петли |
| Голландский угол | SH050 (5°), SH070 (8°), SH120 (12°) | отключён до паранормального | PASS: в проходе 1 горизонт ровный |
| Резкий разворот на испуг | SH110 | джампскер, разворот к источнику звука | PASS: не при спокойном осмотре |
| Паническая ручная камера | SH100 | бег с фонариком; исключена, где надо рассмотреть окружение | PASS: коридор осматривать не нужно |
| Медленный пролёт сквозь объёмный свет | SH020 | движение перпендикулярно лучам | PASS: камера едет на север вдоль окна, лучи идут на запад |
| Слепой наезд в темноту | SH080 | приближение к чёрному участку | PASS |
| Ручная панорама за лучом фонарика | SH100 | ракурс дёргается вслед за лучом | PASS, вместе с паникой: одно движение «ручная камера за лучом» |
| Облёт силуэта с контровым светом | SH120 | фигура спиной к источнику | PASS: Жилец спиной к эркеру |
| Спуск из тени к свету | SH060 | от тёмного потолка к лицу, освещённому лампой снизу | PASS |

Один шот — одно движение камеры. Голландский угол — это постоянный завал кадра, а не движение, поэтому он сочетается с панорамой или дрейфом.

## 3. Свет: где какой приём

| Приём | Шоты |
|---|---|
| Жёсткая светотень, до 70 % тьмы | нарастает: 45 % (SH010–040) → 65 % (SH050–080) → 75 % (SH090–135) |
| Объёмный свет сквозь дождь и пыль | SH020, SH070, SH120 (три луча из эркера) |
| Движущиеся тени против источника | SH070: тень распятия вытягивается вверх, хотя лампа неподвижна. Физически объяснённые движения теней: SH020 (фары автобуса), SH100 (балясины в луче), SH120 (крутящийся фонарик) |
| Мерцающий источник | SH040 и SH080 (лампа мигает и гаснет), SH100 (фонарик мигает и гаснет на 4,6–5,2 с), SH110 (возвращается после удара о косяк) |
| Холодная палитра с янтарными вкраплениями | всё время; янтарь пропадает после смерти лампы |
| Зловещий контровой свет | Жилец всегда; Рут в SH110 (силуэт в коридоре) |

## 4. Склейки: где какая (монтаж, ffmpeg/DaVinci)

| Склейка | Где | Ориентир |
|---|---|---|
| Smash cut | SH080→SH090, SH140→чёрный | щелчок включённого фонарика / щелчок реле |
| Match cut по тени | SH070→SH080 (тёмный абажур потолочной лампы закрывает объектив, SH080 начинается в черноте её спины), SH100→SH110 (луч уходит, коридор чернеет) | чёрный кадр на стыке |
| Match cut по форме | внутри SH040: круглый циферблат → круглый глаз в щели шкафа (0,4 с) | центр круга в одной точке экрана |
| Эллиптический монтаж | внутри SH100: дважды вырезать по 3–4 кадра из бега | на 2,0 с и на 4,0 с |
| Медленный наплыв по фактуре | SH135 (лицо → обои с распятием → рассвет SH140) | 3 с, кроссфейд |
| J-cut | SH040→SH050 (её записанный голос за 1,0 с до картинки), SH060→SH070 (треск винила за 0,8 с) | звук раньше кадра |
| Обычная склейка на действии | остальные стыки | фаза движения совпадает |
