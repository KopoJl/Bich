# «Последняя дверь» (The Last Door) — 3D-мультфильм 45 с

Отдельный проект в репозитории (не путать с «03:06» в корне). 16:9, 720p, 24 fps, Seedance 2.5, без диалогов.

| Папка | Что внутри |
|---|---|
| `00_bible/style_lock.md` | выбор стиля (Expressive Family 3D с shoootai.com), Style Lock, палитры, Light Lock |
| `00_bible/characters.md` | Character Lock Уиллы (плащ / пижама), Пипа, кораблика + промты карт |
| `00_bible/locations.md` | станция и детская: Location Lock + промты карт |
| `00_bible/animation_principles.md` | 12 принципов анимации → конкретные фразы промта |
| `01_script/script.md` | логлайн, структура, хук, драматургия, биты, актёрские задачи |
| `02_storyboard/storyboard.md` | shot list, GEOMETRY и карточки 8 шотов |
| `03_prompts/` | SH010: Start Frame + клип |
| `log.md` | журнал генераций |

## Порядок производства
1. Карты: Уилла (плащ) → правка в пижаму → Пип → кораблик → станция → детская. Утвердить.
2. SH010 Start Frame → утвердить → клип SH010 (пробный дубль).
3. Первыми пробовать рискованные шоты: SH040 (рука насквозь), SH045 (два лица одной девочки).

## Генераторы (решение пользователя)
- Картинки (карты, локации, ключевые кадры): **GPT image 2.6** в Buzzy (`gpt-image-2.6-sunburst` / `gpt-image-2.6-flare`), 16:9, 2k. Первые карты и их правки сделаны ещё на gpt-image-2.
- Видео: Seedance 2.5, 720p.
